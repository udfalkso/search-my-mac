# Search My Mac support

Search My Mac searches document text and, with an optional local model, document meaning in folders you choose.

## Getting started

1. Choose a folder containing local documents to index.
2. Wait for the first documents to appear in the index, then enter a search phrase.
3. Use filters to narrow your results. Select a result and press Space for Quick Look.
4. Open Semantic settings if you want to download the optional model for semantic and hybrid search.

Indexing is progressive. You can start searching before all documents have been indexed. Closing the window leaves indexing running; choose Quit to stop the app.

## Trial and full unlock

The App Store download is free. Choose **Start 7-day Free Trial** to use all features for one week. The trial does not charge you automatically. After it ends, searching and indexing pause until you choose the one-time full unlock. Your documents and local index are preserved.

The full unlock costs US $9.99; the app displays Apple's current price in your local currency before purchase. There is no subscription. Use **Restore Purchases** with the Apple account used for the original purchase to restore access on another Mac. Restoring a trial retains its original start date.

## Troubleshooting

- **Missing results:** Check Index Health for unreadable files or extraction failures. Confirm that the folder is selected and the volume is available. Cloud-only files may need to be downloaded using the cloud provider first.
- **Semantic mode uses text search:** Semantic search becomes available after the model is installed and at least one document passage has a searchable embedding.
- **Indexing seems slow:** The app reduces background work when it is inactive and gives searching priority. Large documents and image OCR can take longer.
- **Folder access after moving files:** Remove and select the folder again if its saved permission can no longer be restored.
